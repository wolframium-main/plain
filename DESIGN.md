# plain — дизайн

Этот документ — источник истины для всех решений. Новая функция или настройка
появляется в коде только после того, как её обоснование появилось здесь.

## Проблема

Современные браузеры перегружены интерфейсом, пытаются быть умными, а большая
часть их функций бесполезна. При этом настроить можно всё, то есть решения
переложены на пользователя.

## Принципы

1. **Интерфейс не мешает.** На экране только то, без чего нельзя обойтись.
2. **Браузер предсказуемый, а не умный.** Делает ровно то, что сказали: никаких
   подсказок, автодействий, рекомендаций и ИИ.
3. **Функций мало.** Каждая должна доказать, что она необходима.
4. **Настроек мало.** Решения принимаем мы, а не перекладываем на пользователя.
5. **Браузер не подстраивается под привычки, а формирует новые.**
6. **Браузер не опекает пользователя** и не защищает его от самого себя.

Приватность — не цель проекта.

## Платформа и технологии

| Решение | Почему |
|---|---|
| Только Linux | Это единственная платформа, на которой браузер нужен автору. |
| Свой браузер на встраиваемом движке, без форков | У нас своё видение; форк — это чужие решения и вечная борьба с апстримом. |
| QtWebEngine (Chromium) | Сервисы Google работают безупречно, есть перехват запросов и DevTools. |
| C++, Qt 6, CMake | Родной язык Qt; кода мало, поэтому удобство Python не окупается. |

## Что браузер помнит

| | Решение | Почему |
|---|---|---|
| Назад / вперёд во вкладке | Есть, только в памяти | Без этого навигация невозможна. |
| История посещений | Нет | Функций мало. |
| Восстановление закрытых вкладок | Нет | Функций мало. Закрытая вкладка закрыта навсегда. |
| Закладки | Нет | Функций мало. |
| Куки и логины | Сохраняются | Браузер, где каждый день входишь заново, не простой, а неудобный. |
| Вкладки прошлого запуска | Не восстанавливаются | Следует из отсутствия истории. |

## Окно и вкладки

- **Одно окно.** Второй запуск `plain` передаёт адрес уже открытому окну.
- **Не больше 5 вкладок**, число фиксировано. Если вкладок нужно помнить много,
  то их открыто слишком много.
- **Вкладки скрыты.** Список показывает команда `:tabs`.
- **Шестая вкладка:** появляются список и строка с `:close `. После закрытия
  одной вкладки новая открывается сама. Намерение пользователя не теряется.
- **Сайт просит новую вкладку — получает новую вкладку.** Браузер не
  переинтерпретирует ссылки. Такая вкладка тоже подчиняется лимиту.
  Попутно работает вход через Google и GitHub во всплывающем окне.
- **Окна, открытые без действия пользователя** (рекламные попапы), блокирует
  сам Chromium, как и в Chrome.

## Интерфейс

На экране только страница. Всё остальное появляется по требованию внизу окна,
поверх страницы:

```
1 · news.ycombinator.com
Hacker News
──────────────────────────
2 · doc.qt.io
Qt 6 Docs                       ← текущая: ink, остальные ink-2
──────────────────────────
Загружено: ~/Загрузки/report.pdf
┌──────────────────────────┐
│ :close █                 │    ← поле в янтарном кольце фокуса
└──────────────────────────┘
```

- **Адресная строка скрыта полностью.** Защита от фишинга — не задача браузера.
  Google Safe Browsing не используется.
- **Тонкая линия загрузки** (2px) внизу страницы во время загрузки.
- **Контекстное меню** из трёх пунктов, в зависимости от того, по чему кликнули:
  «Копировать», «Копировать ссылку», «Сохранить картинку». Если ни один не
  подходит, меню не появляется.
- **В заголовке окна** — заголовок страницы. Его рисует система, не браузер.

## Внешний вид

Всё, что рисует сам браузер, следует дизайн-системе **Wolframium**, тема
«Ночь». Тема одна и не зависит от окружения рабочего стола: «Бумага» в системе
нужна для печати, а браузер не печатается. Код — `src/Theme.h` (токены и
стили текста) и `src/Panel.cpp` (панель).

### Выведено из правил системы

- **Шрифты.** Сообщения, вопросы, заголовки вкладок и ввод — `body` (IBM Plex
  Sans 15/24). Номера и домены вкладок, подсказка клавиш — `meta` (IBM Plex
  Mono 12/16, `ink-3`). Подписи пунктов меню — `body-strong`.
- **Поле ввода** — по правилу поля: фон на ступень в сторону от панели
  (`bg` на `surface`), рамка `line-strong`, скругление `radius`, высота 40px,
  отступы `space-1` / `space-2`, текст `ink`, внутри — настоящий пример цветом
  `ink-3` («doc.qt.io, маятник Фуко или :tabs»). Не шире колонки текста, 640px.
- **Кольцо фокуса** вокруг поля: `focus` (в «Ночи» это янтарь), 2px, отступ
  2px. Поле в фокусе всё время, пока видно, поэтому и кольцо видно всегда.
- **Список вкладок** — по правилу списка: строки разделены линией `line`,
  `space-2` с обеих сторон разделителя, метаданные `meta` над заголовком:
  `2 · doc.qt.io`, ниже «Qt 6 Docs».
- **Сообщения:** результаты `ink-2`, ошибки `danger`, вопросы и висящие
  сообщения `ink`. Не шире 640px (68 знаков). Ошибка говорит, что случилось,
  потом что делать. Голос: коротко, на «ты», без восклицательных знаков.
- **Подсказка клавиш** — `meta` `ink-3` рядом с полем:
  «y — разрешить · n или Esc — запретить».
- **Контекстное меню** — контейнер на `surface-raised`, рамка `line`,
  скругление `radius`, без тени. Пункты — тихие нажимаемые: `body-strong`,
  отступы `space-1` / `space-2`, высота 40px, глагол первым.
- **Движение.** Панель появляется за 120ms ease-out: прозрачность и сдвиг на
  8px. Меню проявляется так же там, где окно может менять прозрачность (не в
  Wayland). Если в KDE скорость анимации — «мгновенно» или в GNOME анимации
  выключены, движения нет.
- **Пустая вкладка** — фон `bg`. Под настоящими страницами — белый, как ждут
  сайты без собственного фона.
- Значков нет нигде.

### Дополнено для plain

В Wolframium нет готового правила для этих элементов. Правила ниже придуманы
для plain по духу системы. Если они приживутся, их стоит перенести в саму
систему.

- **Индикатор загрузки** — линия 2px цветом `ink-3` вдоль нижнего края
  страницы, а когда открыта панель — вдоль её верхнего края. Ход загрузки —
  величина, а величины система рисует линиями данных толщиной 2px; `ink-3` —
  цвет второстепенной серии. Он читается и на белых страницах (3,3:1), и на
  `bg` (5,9:1). Не янтарь: янтарь как линия — только ссылки, фокус и одна
  кривая на чертеже.
- **Текущая вкладка** в списке — заголовок `ink`, остальные `ink-2`, как
  текущий раздел в навигации. Без янтаря и без подложки.
- **Панель** — полоса у нижнего края окна, а не карточка: фон `surface`,
  линия `line` только со стороны страницы, без скругления (полоса уходит за
  край окна), внутри `space-3` по бокам и `space-2` сверху и снизу, между
  частями `space-2`. Она ложится поверх страницы, а не сдвигает её: страница
  не прыгает при каждом открытии строки.
- **Пункт меню под указателем или клавиатурой** — выделенный блок: `violet`
  под `on-violet`, как выделенный текст. Обычное наведение тихого элемента
  (фон `surface-raised`) в меню не видно: меню уже на `surface-raised`. Мышь
  и клавиатура в меню выбирают один и тот же пункт, поэтому выделение служит
  и фокусом.
- **Иконка plain** — своя, не знак Wolframium: ячейка `violet` со скруглением
  `radius`, в ней двоеточие из двух квадратов `on-violet` (кругов в системе
  нет, где круг ничего не значит). Двоеточие — то, с чего начинается любая
  команда. `assets/plain.svg`.
- Янтарь в браузере — только кольцо фокуса. «Смотри сюда» на экране всегда
  принадлежит странице.

## Управление

Управление только через командную строку: команду нужно осознанно напечатать,
поэтому импульсивных действий нет. Единственная горячая клавиша — **Ctrl+;** —
открывает строку. Это клавиша, на которой находится двоеточие, а с двоеточия
начинается любая команда. Ctrl+L из других браузеров не взята намеренно: браузер
не подстраивается под привычки.

| Ввод | Действие |
|---|---|
| адрес | открыть в текущей вкладке |
| любой текст с пробелом или без точки | искать в Google |
| `:new [адрес]` | новая вкладка (пустая — сразу со строкой) |
| `:tabs` | список вкладок |
| `:tab N` | перейти на вкладку N |
| `:close [N]` | закрыть текущую или N-ю |
| `:back`, `:forward`, `:reload` | навигация |
| `:find текст` | поиск по странице; повтор — следующее совпадение, `:find` — сброс |
| `:zoom N` | масштаб в процентах, 25–500 |
| `:url` | скопировать адрес страницы |
| `:proceed` | открыть страницу с недействительным сертификатом |
| `:devtools` | инструменты разработчика |
| `:quit` | выйти |

Поиск — только Google, без настройки.

## Остальное

- **Загрузки** сохраняются в системную папку загрузок без вопросов, файлы не
  перезаписываются (`file (1).txt`). Менеджера загрузок нет.
- **PDF** не показывается внутри: файл сохраняется и открывается системной программой.
- **Блокировка рекламы** встроена и не настраивается: EasyList, обновляется раз
  в 4 дня. Блокируются запросы к рекламным доменам; страницу, на которую
  перешёл сам пользователь, браузер не блокирует никогда.
- **Разрешения сайтов.** Камера, микрофон и показ экрана — вопрос в нижней
  строке: «meet.google.com просит камеру и микрофон. Разрешить? y/n». Ответ не
  запоминается: следующий запрос спросят снова, даже в той же вкладке. Всё
  остальное (уведомления, геолокация, буфер обмена, захват мыши) запрещено без
  вопросов: именно это делает браузер навязчивым.
- **Недействительный сертификат.** Страница ждёт, а внизу висит сообщение:
  «Сертификат example.com недействителен: просрочен. :proceed — открыть всё
  равно». Открыть можно только осознанно, напечатав команду; переход куда-то
  ещё означает «нет». Сообщение привязано к своей вкладке. После `:proceed`
  этот сайт открывается без вопросов до перезапуска браузера (так устроен
  Chromium). Если сайт сам запретил открывать себя без защиты (HSTS), открыть
  его нельзя.
- **DevTools** открываются справа в том же окне.
- **Полноэкранное видео** работает.

## Исключения для сайтов

Браузер ведёт себя одинаково на всех сайтах. Исключение появляется, только
если без него нужный сайт не работает, и каждое записывается здесь. Код —
`src/Quirks.h`.

1. **Вход в Google.** Google не пускает в аккаунт браузеры на QtWebEngine
   («Не удалось войти в аккаунт. Возможно, этот браузер или приложение
   небезопасны»). На `accounts.google.com` plain представляется Firefox 155
   для Linux: и в заголовке User-Agent, и для скриптов страницы. Переход с
   этой страницы на другой сайт маскировку не переносит. Тот же приём
   использует qutebrowser (`ua-google`). Проверено: вход работает. Если
   Google начнёт называть браузер устаревшим, нужно поднять версию Firefox.

## Убрано

Менеджер паролей (есть KeePassXC и pass), расширения, синхронизация, профили,
приватный режим, встроенный просмотр PDF, режим чтения, переводчик, ИИ, лента на
новой вкладке, поисковые подсказки, боковые панели, скриншоты, VPN, кошельки,
HTTP-авторизация (окно логина и пароля от браузера: страницы, которым она нужна,
просто не открываются).

## Решения, принятые при реализации

Они следуют из принципов, но не обсуждались отдельно. Каждое можно пересмотреть.

- **Esc** или клик по странице закрывают строку. Если в этот момент ждала
  отложенная вкладка, она отменяется.
- Закрытие **последней вкладки** оставляет пустую вкладку с открытой строкой.
  Выход — только `:quit`: закрыть браузер случайно нельзя.
- Опечатка в команде **не закрывает строку**, чтобы её можно было исправить.
- Вкладка, открытая **в фоне** (клик колёсиком), сообщает свой номер.
- plain представляется сайтам **обычным Chrome** той версии, на которой
  построен: из User-Agent убрана метка `QtWebEngine/x.y`. С ней Google
  принимает браузер за робота и показывает капчу.
- Блокировщик учитывает только правила для **целых доменов**, остальные
  пропускает: лучше пропустить рекламу, чем сломать сайт.
- На вопрос о разрешении «да» — это `y`, `yes`, `д`, `да` и `н` (клавиша Y в
  русской раскладке). Любой другой ответ, Esc или клик по странице — «нет».
  Несколько запросов подряд задаются по очереди.

## Лицензия

**GPL-3.0 или новее.** Код открыт, и любая изменённая версия, которую
кто-то распространяет, тоже обязана быть открытой: никто не выпустит
закрытый «plain с рекламой». QtWebEngine распространяется под LGPL и с GPL
совместим.

## Распространение

Пакет для Arch Linux в AUR: `plain`. Исходники — на GitHub,
`wolframium-main/plain`; пакет собирает браузер из тега релиза с системным Qt.

- `packaging/aur/` — PKGBUILD и .SRCINFO для AUR.
- `packaging/arch/` — сборка из этого дерева исходников, для разработки.

Других пакетов (Flatpak, deb) нет.
